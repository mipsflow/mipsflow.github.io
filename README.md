# MIPSflow · מסע של פקודה

**לאתר: https://mipsflow.github.io/**


סימולטור לימודי בעברית שממחיש כיצד פקודות MIPS עוברות במעבד חד־מחזורי ובמעבד צינורי בן חמישה שלבים. מטרת הפרויקט היא לעזור ללומדים לעקוב אחרי ערכי האוגרים, קווי הבקרה, המעברים בין תחנות הצינור, forwarding, בועות ו־flush.

## תכונות

- בחירה בין מעבד חד־מחזורי למעבד צינורי (IF, ID, EX, MEM, WB).
- הצגת קידוד פקודות וטבלת אותות בקרה.
- תרשימי SVG אינטראקטיביים עם נתונים והסברים על הקווים.
- מעקב אחר פקודות ורצפים והדגמת סיכוני נתונים.
- מעקב קוד חופשי: מדביקים קוד MIPS ורואים טבלת מחזורים עם forwarding, בועות ו־Flush.
- בדיקות יחידה לסימולטור ובדיקת דפדפן אוטומטית לכל המצבים, כולל תצוגת טלפון.

## טכנולוגיות ודרישות

- HTML ו־CSS בדפדפן; JavaScript ES Modules.
- Node.js 18 ומעלה לשרת פיתוח, בדיקות ובנייה.
- האתר עצמו בלי תלויות חיצוניות. Playwright משמש רק לבדיקות הדפדפן.

## הרצה

1. חלצו את תיקיית הפרויקט או שכפלו את המאגר.
2. התקינו Node.js 18 ומעלה.
3. מתוך תיקיית הפרויקט הריצו `npm run dev`.
4. פתחו בדפדפן את כתובת localhost שמוצגת בטרמינל. יש להגיש דרך HTTP כדי ש־ES Modules ייטענו.

פקודות נוספות:

```sh
npm test            # בדיקות יחידה (בלי התקנות)
npm install         # פעם אחת, לבדיקות הדפדפן
npx playwright install chromium
npm run test:e2e    # בדיקת דפדפן לכל המצבים והלשוניות
npm run build       # יוצר את dist/
```

הבנייה יוצרת את `dist/`, שאפשר לפרסם באחסון אתרים סטטי. אין לפתוח את הדף מתוך `dist` דרך `file://`.

│   │   ├── base.css           # העיצוב הבסיסי

│   ├── state/store.js         # ניהול מצב
│   ├── simulator/             # קידוד, ערכים מיידיים, תזמון הצנרת, forwarding וסיכונים

│   └── e2e/                   # בדיקת דפדפן (Playwright)

## שמירת המראה המקורי

קובץ המקור שהועלה נשמר כנקודת הייחוס. ב־`index.html` נשמרו ה־HTML וה־SVG המקוריים. העיצוב נמצא ב־`src/styles`, והלוגיקה בקובצי JavaScript נפרדים לפי תחום. נוספו רק התאמות ממוקדות לתצוגת המעבד הצינורי: תרשים גדול יותר, הדגשה זורמת של הקווים, וסידור טבלת המחזורים אחרי התרשים. במעבד החד־מחזורי טבלת הבקרה מוצגת אחרי התרשים, ובמעבד הצינורי טבלת המחזורים מוצגת אחריו.

## בדיקות

`npm test` מריץ 15 בדיקות יחידה: קידוד, ערכים מיידיים בעשרוני ובהקסה, forwarding, load-use, `beq` שמוכרעת ב־ID, Flush, ורצף בסגנון מבחן שבו במחזור 5 הצנרת נראית בדיוק כמו בשרטוט המבחן.

`npm run test:e2e` פותח את האתר בדפדפן, עובר על כל המצבים, הלשוניות והפקודות, ונכשל על כל שגיאת JavaScript. הוא גם מריץ את בדיקת התקינות הפנימית (58 בדיקות), מריץ קוד בסגנון מבחן במעקב הקוד, ובודק שבטלפון אין גלילה הצידה.
